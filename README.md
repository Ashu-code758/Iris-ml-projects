# Iris Machine Learning Project

This is a Machine Learning project. It uses a trained model on the Iris flower dataset and shows predictions using a Streamlit web app.

##  Files

- `Iris_dataset.ipynb` - Notebook where model is trained
- `Iris_model.pkl` - Saved trained model (pickle file)
- `app.py` - Streamlit web application
- `Iris.xlsx` - Dataset file
